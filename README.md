# Controle de Público

Aplicativo para registro de público por indicadores designados (até 100 indicadores, dois eventos anuais).

## Estado
Prévia visual inicial implementada em `index.html`, `styles.css` e `app.js`. **Os dados são demonstrativos: não há envio real nem autenticação administrativa.**

## Próximas entregas
Google Sheets, backend Apps Script, validação e prevenção de duplicidades, autenticação administrativa, testes e publicação.

## Segurança
Não publicar nomes reais, telefones, tokens, credenciais ou IDs privados. O repositório está público neste momento; recomenda-se torná-lo privado.
